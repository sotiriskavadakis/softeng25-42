⚡ Quick Start

1. Get a Token

curl -X POST http://localhost:9876/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"pass123"}'

2. Use Token in Requests

curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:9876/api/points

3. Check Health (No Auth)

curl http://localhost:9876/api/admin/healthcheck

🔐 Authentication

All endpoints except /auth/* and /admin/healthcheck require JWT authentication.

JWT Bearer Token

Validity: 24 hours from issuance

Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Security

  • Passwords hashed with bcrypt (never stored in plain text)
  • Tokens are stateless (no session storage)
  • No email enumeration (generic error for invalid credentials)
  • Slow hashing to prevent brute force attacks

🔌 API Endpoints

POST /auth/register

POST Register a new user account

Request:

{
  "email": "user@example.com",
  "password": "securePassword123",
  "username": "john_doe"
}

Response (200 OK):

{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}

POST /auth/login

POST Authenticate and get JWT token

Request:

{
  "email": "user@example.com",
  "password": "securePassword123"
}

Response (200 OK):

{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}

GET /admin/healthcheck

GET Check API health (no auth)

Response (200 OK):

{
  "status": "OK",
  "n_charge_points": 1454,
  "n_charge_points_online": 1416
}

GET /points

GET List all charging points

Query Parameters:

  • status - Filter by status
  • lat, lng, radius - Radius search
  • min_lat, max_lat, min_lon, max_lon - Bounding box
  • format - json or csv

Example:

curl "http://localhost:9876/api/points?lat=37.9838&lng=23.7275&radius=50"

GET /point/{id}

GET Get point details

Example:

curl http://localhost:9876/api/point/3508687

POST /reserve/{id} or /reserve/{id}/{minutes}

POST Reserve a charging point

Auth Required

Examples:

# 30 minutes (default)
curl -X POST http://localhost:9876/api/reserve/3508687 \
  -H "Authorization: Bearer token123..."

# Custom 45 minutes
curl -X POST http://localhost:9876/api/reserve/3508687/45 \
  -H "Authorization: Bearer token123..."

POST /newsession

POST Record a charging session

Auth Required

Request:

{
  "pointid": "3508687",
  "starttime": "2025-12-25 10:00",
  "endtime": "2025-12-25 11:30",
  "startsoc": 20,
  "endsoc": 80,
  "totalkwh": 45.5,
  "kwhprice": 0.35,
  "amount": 15.93
}

GET /sessions/{id}/{from}/{to}

GET Get charging sessions

Auth Required

Path Params:

  • id - Point ID
  • from - Start date (YYYYMMDD)
  • to - End date (YYYYMMDD)

Example:

curl -H "Authorization: Bearer token123..." \
  "http://localhost:9876/api/sessions/3508687/20251201/20251225"

❌ Error Handling

Error Response Format

{
  "error_code": "VALIDATION_ERROR",
  "error_message": "Description",
  "timestamp": "2025-12-25 14:30"
}

Error Codes

Code HTTP Status Meaning
VALIDATION_ERROR 400 Input validation failed
INVALID_CREDENTIALS 401 Wrong email/password
UNAUTHORIZED 401 Missing or invalid token
DUPLICATE_EMAIL 409 Email already registered
NOT_FOUND 404 Resource doesn't exist

📊 Status Values

Status Meaning
AVAILABLE Ready for charging
OCCUPIED Currently charging
RESERVED Reserved for future use
FAULTED Hardware malfunction
OFFLINE Not operational

💡 Complete Workflow

#!/bin/bash

# 1. Login
TOKEN=$(curl -s -X POST http://localhost:9876/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"pass123"}' \
  | jq -r '.token')

# 2. Find points
curl "http://localhost:9876/api/points?lat=37.9838&lng=23.7275&radius=50" | jq

# 3. Reserve
curl -X POST http://localhost:9876/api/reserve/3508687/45 \
  -H "Authorization: Bearer $TOKEN" | jq

# 4. Record session
curl -X POST http://localhost:9876/api/newsession \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"pointid":"3508687","starttime":"2025-12-25 10:00",...}'

❓ Troubleshooting

401 Unauthorized

Check: Is token in header? Valid format: Authorization: Bearer <token>. Tokens expire after 24 hours.

404 Not Found

Check: Is point ID correct? List all points: GET /points

400 Bad Request

Check: JSON syntax valid? Required fields present? Date format correct: YYYY-MM-DD HH:MM or YYYYMMDD

204 No Content

NOT an error! No results found. Try broader filters.
